Machine Learning Based Auto Insurance Pricing System

This project is a desktop application that calculates motor insurance premiums dynamically using Machine Learning algorithms, replacing traditional rule-based evaluation methods. 

## Project Overview
The primary objective of this system is to evaluate customer risk (no-claim discount tier) and vehicle value to accurately estimate insurance premiums. By utilizing a `LinearRegression` model trained on historical customer data, the system autonomously determines pricing. This eliminates the need for manual, hard-coded rate adjustments and creates a more data-driven pricing architecture.

## Technologies Used
* **Python:** Core programming language
* **Scikit-Learn:** Machine learning framework (Linear Regression)
* **SQLite:** Relational database management for customer records
* **GUI Framework:** Tkinter / PyQt (Desktop interface)
